# Music credits

Most tracks are **placeholders** (PLAN.md open question 2): short synth loops
built at runtime by `Sound._synth()` in `autoload/sound.gd` from the recipes in
`Sound.TRACKS`. Original to this project, no license restrictions.

Recorded tracks live here as mp3 and are listed in `Sound.FILES`, which wins
over a synth recipe of the same name. They loop on load. An array entry picks
one file at random each time the track starts.
